# Security policy

## Supported versions

Security fixes go into the latest release only. Upgrade to it before reporting a problem.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub's vulnerability reporting](https://github.com/breww-oss/django-deferred-migrations/security/advisories/new) instead.

Include the version, your Django and PostgreSQL versions, and the steps that reproduce the problem. We aim to acknowledge a report within a week, and will agree a disclosure date with you once a fix is ready.
